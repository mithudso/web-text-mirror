# AGENTS.md

Catalog of repo-local agents.

This repository defines **no repo-local agents**. Global/user-level agents (code
review, security review, doc critique) apply as usual; nothing here overrides them.

Guidance for any coding agent working in this repo lives in `CLAUDE.md` (Claude),
`.github/copilot-instructions.md` (Copilot), and `GEMINI.md` (Gemini). The key
conventions section of `CLAUDE.md` is the canonical rule set — the other two mirror it.
